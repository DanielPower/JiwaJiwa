# core/AGENTS.md

Pure-Kotlin study logic. It must stay free of Android imports so it builds
and tests on any JVM (`./gradlew -PcoreOnly=true :core:test`).

## Files

| File | What's in it |
| --- | --- |
| `Fsrs.kt` | A port of FSRS-6 (py-fsrs 6.3.2), with learning steps and fuzz. `FsrsTest` replays `src/test/resources/fsrs_vectors.tsv`, generated by `tools/fsrs/gen_vectors.py`. If you change the scheduler, regenerate the vectors rather than editing them. |
| `Cards.kt` | `Card`, `WordProgress`, `ReviewLog`, and `Reviewer`, which applies an answer (FSRS + mastery + production unlock), introduces a new word, or marks it known. |
| `Mastery.kt` | `MasteryRules`: stability ↔ mastery mapping and the furigana thresholds. |
| `StudyClock.kt` | Study days with a rollover hour, in a time zone. Review cards fall due at the start of a study day. |
| `Session.kt` | `StudySettings`, `StudyAhead` ("study more"), `DailyLimits`, and `StudySession`, the order cards are shown in during one sitting. |
| `Kana.kt` | Romaji → kana for search, hiragana/katakana variants. |
| `KanaCourse.kt` | The kana units (negative ids, so they never clash with JMdict word ids), teaching order, and the "kana known" setting. |
| `Reading.kt` | Kuromoji tokens grouped into words, matched to the dictionary, with conjugation labels. |
| `Grammar.kt` | About 100 hand-written grammar points (particles and N5–N3 patterns), each with token patterns over Kuromoji output. `Reader` attaches them to words; a match inside a longer match is dropped. `GrammarTest` checks every point's own example sentence finds it, so add an example that does. |
| `Stories.kt` | Graded-reader story requests, budgets of new words, prompts, and the rewrite loop. |
| `Claude.kt` | A minimal Messages API client over `HttpURLConnection`. The Anthropic Java SDK was too heavy for the APK. Model `claude-opus-5-5`, effort high, server-side fallbacks on. The `send` parameter is the seam for tests. |
| `RenshuuImport.kt` | Plans a Renshuu mastery import (take the higher). |

## Things that are easy to get wrong

- Mastery follows the recognition card (and kana cards). Production answers
  must not change it.
- `Direction` and `CardState` values are stored in the app's database. Don't
  renumber them; add new values at the end.
- Kana cards use `Direction.KANA` with the `KanaUnit` id as the word id.
- Elapsed time for FSRS is counted in study days, not 24-hour periods.
- Times are epoch milliseconds; days are epoch days of the study day's
  calendar date. Tests use `America/St_Johns` (a half-hour offset with DST)
  to catch time zone mistakes.

## Tests

`src/test/kotlin`, JUnit 5 via `kotlin.test`. Name tests as backtick
sentences about behaviour. Anything the app does that doesn't need Android
should be pulled into core and tested here.
